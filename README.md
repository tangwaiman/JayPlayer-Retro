本專案不只是一個播放器，而是一整套完整的數位音樂收藏工作流（Workflow）。

### 🛠️ 老兵音樂封裝四部曲（核心工作流）

為了確保 100% 成功不踩雷，請嚴格遵循以下四個步驟進行測試與封裝：

#### 第一關：CD 擷取 (Audio Ripping)
1. 拿出你的正版周杰倫實體 CD，放入電腦的光碟機。
2. 使用 Windows Media Player 內建的「擷取（Rip）」功能，將音樂擷取為 `MP3`、`WAV` 或 `WMA` 格式。
3. 將這些擷取出來的音樂檔案，通通丟進一個名為 `C:\music_raw` 的臨時資料夾中。
   * *此時的檔名通常會長這樣：`01. 晴天.mp3` 或 `02 七里香.wma`。*

#### 第二關：歌詞爬取 (Lyrics Fetching)
1. 打開 `lyrics_fetcher.py`，將裡面的 `MUSIC_DIR` 修改為你的臨時資料夾路徑（`C:\music_raw`）。
2. 在命令列執行它。程式會自動讀取你剛擷取的音樂檔名，透過免費開源的 `LRCLIB API` 在網路上搜尋對應的歌詞，並自動生成同名的 `.txt` 檔案。
3. **安全把關**：下載完後，建議人工打開一兩首 `.txt` 檢查歌詞是否完整。

#### 第三關：批次改名與封裝 (Safe Renaming)
1. 這是最關鍵的一步！為了防止檔案系統在改名時「檔名撞車」或「檔案行進中失蹤」的經典地雷，我們採用**「緩衝區思維」**。
2. 確認你的原始檔案在 `C:\music_raw`。
3. 執行 `rename_tool.py`。程式會自動將音樂依照順序重新命名為 `001.mp3`, `002.wma`... 並自動補零。
4. **格式優化**：此工具會自動將「乾淨的中文歌名」強行塞入對應 `.txt` 歌詞檔的**第一行**，以完美適配後續播放器的排版！
5. 最終處理完成的「標準老兵音樂檔」會整整齊齊地存放在 `C:\music` 資料夾中，並自動生成一份 `000_index.txt` 索引清單。

#### 第四關：啟動播放 (Ultimate Playing)
1. 確保你的 `music_player.pyw` 和 `python.exe` 放在同一個資料夾。
2. 在案頭 Double-Click（連點兩下）`run.bat`。
3. 你的老舊小筆電會瞬間進入**純黑背景、白字歌名、優雅淺灰歌詞**的全螢幕 KTV 屏保世界！
4. **快捷鍵操作**：
   * `Esc`：一鍵關閉播放器，並自動安全清理後台 `old_soldier_temp` 暫存檔。
   * `→` (右方向鍵)：100% 連貫自動跳下一首隨機歌曲。
   * `←` (左方向鍵)：返回歷史紀錄上一首。
   * `↓` (下方向鍵)：看下面未顯示的歌詞。

### 🚀 安裝與使用說明 (How to Run)

1. 將本專案的程式碼下載，並命名為 `music_player.pyw`（使用 `.pyw` 可以隱藏後台黑色的 CMD 視窗）。
2. 在 `C:\` 槽建立一個名為 `music` 的資料夾（路徑：`C:\music`）。
3. 把你的正版音樂檔放進去，並準備對應檔名的 `.txt` 歌詞檔：
   * 例如：`001.mp3` 搭配 `001.txt`
   * *提示：歌詞檔的第一行將會被程式抓取，並自動顯示為「中文歌名」！*
4. 點擊本專案附帶的 `run.bat` 批次檔，即可一鍵秒開全螢幕享受音樂！

### 🔥 老兵渡坑神技：如何在無解壓、無網路的 Vista 上建構環境？ (Crucial Setup Guide)

在老舊的 Windows Vista 電腦上，你可能會遇到**「無法下載/安裝現代解壓軟體（如 7-Zip）」**、**「Pip 套件管理員因 SSL 過期無法連網」**等致命大坑。以下是作者親測 100% 成功的極限生存流架設方法：

1. **免安裝 Python 核心**：
   * 不要下載大體積的安裝版，直接在其他電腦下載 **Python 3.4.4 Portable（免安裝綠色版）**。
   * 利用 USB 隨身碟直接複製到 Windows Vista 筆電中。這樣就徹底繞過了「無解壓軟體、無法運行 Installer」的困境。

2. **強行注入 WMP 組件（解決 win32com 缺失大坑）**：
   * 因為無法使用 `pip install pywin32`，請直接在網上搜尋並下載獨立的 `.exe` 安裝包：
     👉 **`py32-221.win32-py3.4.exe`** (或對應 Python 3.4 的 pywin32 二進位安裝檔)
   * 這個舊式的 `.exe` 可以在 Windows Vista 上直接執行，它會自動偵測你的 Python 3.4 路徑，並把調用 Windows Media Player 所需的 `win32com` 核心套件完美安裝進去！

3. **歌詞爬蟲依賴 (`requests`)**：
   * 歌詞爬蟲需要 `requests` 套件。如果 Vista 無法聯網 `pip`，可以在有網路的現代電腦上下載 `requests` 的原始碼資料夾（或是 `.whl` 檔案解包），直接丟進 Python 3.4 的 `Lib/site-packages` 資料夾中即可完成「盲裝」。
